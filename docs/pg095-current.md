# MOSS PG0.9.5 source cohort

Version0.4.0.dev0 pins core0.13.0 at `3dd672a7f9b8c169daef90fd63e4bb42b9ddc423` and published ParticleGAN0.9.5, wheelSHA `c1c0de7a635ac1b1634ba158eed050b6f6aed993e01f9b463435430c77d846ae`. The shared source map covers577 packaged files. The explicit backend is ConditionalPG095; no GAN math is copied.

The product profile is `hypergan-hndl-v3-pg095`. The underlying unchanged HyperGAN/HNDL graph builder retains its own `hypergan-hndl-v2` identity, recorded separately as builder_profile. HyperGAN5f368a/HNDL0.10, model revision, signed attention LoRA, native field geometry and inherited defaults are unchanged. There is no particle bank; prior_lr_mult is refused.

The CLI, common execution profiles, checkpoint headers and portable GAN adapters bind PG0.9.5 and the full source closure. Old PG094 GAN packets require their original source/environment; this migration does not rewrite or convert them. Legacy portable v1 adapters and the explicit historical PG091 reproduction source remain separate. [Prior current-source guide](pg094-current.md) and all historical receipts retain their bytes.

CPU checks use the actual tiny random MOSS architecture and HNDL graphs: optimizer ownership/rates, exact continuation, portable response/OFF, source tamper refusal, rollback, private RNG and common dispatcher. No full pretrained weights or GPU allocation is used. Fresh pretrained PG0.9.5 native256 RAW-response mechanics and learning-rate measurement have now completed through the current source. The [scoped preset and held-out evidence](learning-rates.md#measured-native256-pg095-preset) are separate from these CPU checks and do not qualify a production sampler, VAE, offload path or arbitrary geometry. Previous native observations do not transfer automatically.

Use the new-environment install in README. The hash-checked CPU lock keeps its existing Torch/Pillow/security floors and updates only the official PG archive. UI remains blocked by the existing Pillow/Gradio incompatibility. Active campaigns and foreign worker environments are untouched.
